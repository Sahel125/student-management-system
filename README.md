# student-management-system

A Python-based student management system developed as part of my
Data Structures and Algorithms module.

## Project Overview

The project demonstrates the use of Python programming and
data structures to manage and organise student information.

## Features

- Add student records
- View student records
- Update student information
- Remove student records
- Search for students
- Organise and manage student data

## Data Structures & Algorithms

- Lists / arrays
- Searching
- Sorting
- Data manipulation
- Object-oriented programming, where applicable

## Technologies

- Python
- Data Structures
- Algorithms

## How to Run

1. Download or clone the repository.
2. Open the project in a Python IDE.
3. Run `main.py`.

- Applying data structures to a practical problem
- Implementing searching and sorting techniques
- Organising data within a Python application
